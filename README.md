# ⚠ Only Compatable with v1.0.2

A More Lightweight Version of OWO++, A Fork of SDR++.

## Features for OWO-Lite:
- Custom icons
- Extra Themes
- Bandplan customizations (More coming soon).
- Additional UI tweaks

OWO-Lite is a lightweight version of OWO++, A fork of SDR++ focused on customizing visual elements such as icons, themes, bandplans, etc.

OWO Lite & OWO++ Are Not Affiliated with SDR++ in Any Way.

## Notes:

Previously, release files were too large to upload individually. This has been resolved by packaging them into a ``.zip`` file, now available in Releases.
